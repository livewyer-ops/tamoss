# TAMS brand assets

These SVG assets are from the official TAMS Brand Kit v1.2, published on
2026-09-02:

- <https://tams.org/2026/09/02/TAMS-branding/>
- <https://tams.org/brand/>

The files are kept unchanged from the kit. `tams-lockup-color-light.svg` is the
horizontal colour lockup for light backgrounds. `tams-mark-tile.svg` is the
small-format tiled mark used below the brand kit's 24 px threshold.
